# Northwind Regional Medical Center (simulated)

The simulated hospital the prototype runs against. Everything here is fictional and synthetic; there is no PHI. Procedure (CPT) and diagnosis (ICD-10) codes are real public codes.

| Folder | Stands in for | Read by |
|---|---|---|
| `scheduling/` | The OR scheduling system: suite settings, rooms, shared equipment, block templates, booked cases | `adapters/scheduling_mock` |
| `ehr/` | Patient search, surgical orders, payers, credentialing, the procedure master, case logs | `adapters/directory_fixture`, `adapters/history_csv` |
| `policies/` | The hospital's perioperative policies: structured rules (YAML) and the same policies in prose (Markdown) | `adapters/policy_store_fixture` |
| `inbox/` | Fax server, email gateway and call transcription | `adapters/ingest_fixture` |

Rules live where a real hospital keeps them: scheduling rules on the records they govern (a block's release horizon, a room's turnover, the suite's schedule close), everything else in `policies/`. Nothing about Northwind is in the agent's configuration.

The clock is frozen at **Wednesday, October 14, 2026, 09:00**; requests target the week of **Monday, November 2**. All times are local.

Two simulation shortcuts, both declared in the data:

- `scheduling/booked_cases.yaml` treats every room as fully booked through Oct 30, standing in for weeks of real cases.
- Blocks marked `filler: true` are treated as fully booked by cases the fixture doesn't list.

`ehr/case_history.csv` is generated by `scripts/generate_case_history.py` (fixed seed), tuned so Dr. Patel's robotic knees size to exactly 112 minutes typical and 135 long.
